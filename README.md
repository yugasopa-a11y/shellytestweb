# The Shelly Test

A rigged 23rd birthday personality quiz for Shelly, gifted by Yug and Arham.

Every question has a "calm/reasonable" answer (always CORRECT) and a "true-to-Shelly" answer (always WRONG). The joke is she can never pretend to be chill.

## Features
- 7 themed rounds with unique hand-drawn SVG scenes
- Round 4 seatbelt animation system (recoil → seatbelt → tremor)
- Mini-game: "Escape the Interrogation Room" with 30s timer
- Finale with joke → sincere transition and photo reveal
- Fully mobile-responsive with `prefers-reduced-motion` support
- Single-file app (~52KB) — no dependencies

## Stack
- Vanilla HTML/CSS/JS (no frameworks)
- SVG hand-drawn scenes
- Google Fonts (Space Grotesk + Inter)

## Run
Open `index.html` in a browser. No build step needed.
